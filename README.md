# Klaket — privacy policy

Static privacy policy for the Klaket app (Arabic `index.html`, English `en.html`), served by GitHub Pages:
**https://mohamedmagdy97.github.io/laqta-privacy/** (Settings › Pages › Deploy from branch `main`, folder `/`).

Keep it in step with the app: if a feature ever sends data off the device, update both pages and the date first.

The repo keeps its old name (`laqta-privacy`) so the published URL never changes; the app is **Klaket / كلاكيت**.
